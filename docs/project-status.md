## Ringkasan super singkat

Bot Telegram jalan, bisa di-`python -m app.main` dari Windows dev. Fondasi (Fase 1-3 blueprint) **selesai** dan sudah dikeraskan (global error handler + recovery restart). Game pertama (**Kursi Kosong**): Tahap 0-5 **selesai** (termasuk uji manual sungguhan di Telegram) — game bisa dimainkan sungguhan dari `/game kursi_kosong` sampai ada pemenang. Sistem skor & leaderboard bulanan dan panduan deployment Termux juga sudah selesai dari sisi kode/dokumen (Termux sendiri belum pernah dieksekusi di device sungguhan).

**Baru (2026-08-06): game kedua, Kuis Kenal, Tahap 0-10 selesai dari sisi kode + test otomatis** (`app/modules/games/implementations/kuis_kenal/`) — lihat detail di tabel di bawah. **Belum**: Tahap 11 (test manual di Telegram sungguhan) dan Tahap 12 (kalibrasi produksi) — makanya masih didaftarkan hanya di non-production (`app/bootstrap.py`). Sesi ini juga menambahkan **infrastruktur pytest formal** ke repo (`tests/`, `pytest.ini`, `requirements-dev.txt`) — sebelumnya semua verifikasi Kursi Kosong dilakukan lewat script ad-hoc di scratchpad (tidak committed); Kuis Kenal adalah game pertama yang test otomatisnya benar-benar ada di repo.

**Baru (2026-08-06, susulan): perbaikan "virtual player tidak bisa private chat"** — ditemukan pas mau mulai Tahap 11 (uji manual Kuis Kenal lewat `/p1`-`/p7`): tombol pilih-soal di DM tidak berfungsi sama sekali. Root cause & fix (4 bagian, semua di `app/`, lihat `docs/game-development-guide.md` §14 untuk detailnya): (1) generic in-game callback handler ternyata `GroupOnly()` — semua tombol Kuis Kenal yang hidup di DM (bukan cuma pilih-soal) langsung ditolak, diperbaiki dengan menghapus filter itu; (2) `/p0`-`/p7` sendiri juga `GroupOnly()` — admin tidak bisa ganti persona di chat privatnya sendiri, diperbaiki; (3) urutan `register_modules()` diubah (devtools sebelum games) supaya command `/pN` tidak "ditelan" handler pesan privat generik games saat admin sedang punya konteks jawab/nilai aktif; (4) `judge_nonce` ternyata TIDAK PERNAH digenerate sama sekali sejak awal (bug independen, ditemukan saat mendesain perbaikan ini) — deep link `kk-j` selalu ditolak "tidak berlaku" apa pun yang terjadi, diperbaiki + fase menilai sekarang punya fallback dorong-pesan-gagal → pesan grup dengan deep link (dipakai SELALU untuk virtual player, karena `telegram_user_id` palsu mereka memang tidak pernah punya chat asli). 6 test baru (router-level + integration), total 188 test lulus.

**Baru (2026-08-06, susulan lagi): perbaikan pesan hasil akhir Kuis Kenal** — ditemukan user dari uji manual sungguhan pertama: pesan "🏁 KUIS KENAL SELESAI!" menampilkan ulang render skor ANTAR-RONDE (`render_scoreboard`, berlabel "📊 Skor sementara", isinya skor internal/jumlah jawaban benar) padahal seharusnya sudah final DAN seharusnya menampilkan skor LEADERBOARD (§18 rencana — partisipasi+ketahanan+hasil, bukan cuma jumlah benar). Diperbaiki: modul baru `kuis_kenal/scoring.py` (pola sama seperti `kursi_kosong/scoring.py`) — `compute_scores(state)` jadi SATU sumber kebenaran dipakai baik oleh `calculate_scores()` (commit ke `user_game_scores`) MAUPUN pesan hasil akhir (`_finish_game`), supaya angka yang dilihat pemain tidak pernah beda dari yang benar-benar tercatat ke leaderboard bulanan. Fungsi render baru `render_final_leaderboard()`: label "📊 Perolehan Skor:", medali 🥇🥈🥉 untuk 3 besar, baris AFK pakai 💤 + "(Penalti AFK N poin)" eksplisit (format sama persis seperti Kursi Kosong). Skor internal (jumlah jawaban benar) TETAP dipertahankan HANYA untuk menentukan baris "🏆 ... menang!" (keduanya sengaja angka yang beda, didokumentasikan di `kuis-kenal-implementation-plan.md` §17). Ralat kecil ikut ditemukan: formula halving AFK di draft awal pakai `round()`, ternyata rencana §18.3 minta `floor()` eksplisit — diperbaiki jadi `// 2` literal. 5 test baru (`test_scoring.py`), total 193 test lulus.

**Baru (2026-08-06, sesi terpisah): modul Autoreply/MsgCmd SELESAI dari sisi kode + test otomatis** (`app/modules/autoreply/`), sesuai `docs/Desain_Pengembangan_Autoreply_MsgCmd.md` (semua 7 Tahap rencana implementasi di dokumen itu dikerjakan).
