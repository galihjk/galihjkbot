# Status Project

> Snapshot per **2026-08-05**. Dokumen ini dimutakhirkan tiap kali ada perubahan besar — kalau kamu baca ini di sesi baru, ini adalah cara TERCEPAT untuk tahu "di mana kita sekarang" tanpa baca kode. Detail teknis kenapa sesuatu dibangun begini ada di [`development-history.md`](development-history.md); detail cara nambah game ada di [`game-development-guide.md`](game-development-guide.md).

## Ringkasan super singkat

Bot Telegram jalan, bisa di-`python -m app.main` dari Windows dev. Fondasi (Fase 1-3 blueprint) **selesai** dan sudah dikeraskan (global error handler + recovery restart). Game pertama yang sesungguhnya (**Kursi Kosong**): Tahap 0-4 **sudah selesai** — game bisa dimainkan sungguhan dari `/game kursi_kosong` sampai ada pemenang, dengan jendela kontes kursi berbobot, status `AFK` vs `ELIMINATED` yang benar, reminder countdown 5/3 detik, narasi ronde final, DAN skor akhir (hasil+partisipasi+ketahanan × faktor jumlah pemain) tersimpan ke `user_game_scores`. Tahap 5 (ketahanan produksi) **Bagian A-C sudah selesai** (retry edit pesan + fallback, recovery restart diverifikasi, admin monitoring `/activegames`/`/gameinfo`) — Bagian D (sesi manual sungguhan di Telegram, 3 & 8 pemain) menunggu user. Belum pernah dicoba jalan di Termux/Android TV Box sama sekali (Fase 5 blueprint nol persen).

## Langkah selanjutnya yang paling jelas

Tahap 0-5 (Bagian A-C) sudah selesai (diverifikasi lewat integration test nyata — lihat `development-history.md`). Yang tersisa dari Kursi Kosong adalah **Tahap 5 Bagian D**: sesi manual sungguhan di Telegram (`/p1`.."/p7") dengan 3 pemain dan 8 pemain (maksimum) untuk pastikan layout tombol & narasi terasa pas — ini murni QA manual, bukan kerja coding, menunggu user yang menjalankannya kapan sempat.

Alternatif kalau mau ganti arah dulu: deployment Termux, `/gamesessions`/`/admincancelgame` (sisa item admin monitoring yang sengaja belum dikerjakan), dan uji manual Tahap 5 Bagian D itu jalur-jalur independen — bisa dikerjakan urutan berapa pun, tanya preferensi user dulu kalau mau pindah jalur.
